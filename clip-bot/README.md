# clip-bot

clip-bot is a personal tool run by one person. Each day it takes popular,
publicly available clips from creators who openly allow clipping (through
their clipping programs), turns them into vertical videos with captions and
a credit to the original creator, and posts them to the owner's own TikTok
account.
